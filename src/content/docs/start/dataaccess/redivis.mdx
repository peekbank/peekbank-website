## Clients

Reading a table with the Python client:

```python
import redivis  # uv add redivis

table = (
    redivis.organization("datapages")
    .dataset("peekbank:a3v0", version="v1.4")
    .table("administrations")
)

df = table.to_pandas_dataframe()
```

Authentication uses a `REDIVIS_API_TOKEN` environment variable. For queries and the JavaScript client, see the <a href="https://apidocs.redivis.com/client-libraries" target="_blank">Redivis client documentation</a>.

<details>
<summary>Differences to peekbankr</summary>

peekbankr reshapes some of the Redivis tables before handing them out, creating minor differences to what you would get with direct access:

- peekbankr fetches the `aoi_timepoints` table in the compressed run-length encoding. Accessing the raw table via the Redivis client is a larger transfer, so either run your queries on Redivis before fetching or pull `aoi_timepoints_rle` directly and expand the table yourself.
- peekbankr automatically adds a `dataset_name` column to `administrations`, `subjects`, `trials`, `trial_types` and `stimuli`.
- `trials.excluded` and `trial_types.vanilla_trial` are 0/1 on Redivis, while peekbankr transforms them to TRUE/FALSE.

</details>
