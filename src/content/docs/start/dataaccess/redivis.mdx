## Versions

Every Redivis version of the dataset holds one Peekbank release, named in its `release_info` table. The newest version is `v2.0`, holding [2021.0](../../../peekbank/releases/); the latest full release is `v1.4`, [2026.1](../../../peekbank/releases/). Version tags and release names do not run in step, so pin by the tag you want rather than assuming the highest one is the newest data.

## Clients

Reading a table with the Python client:

```python
import redivis  # pip install redivis

table = (
    redivis.organization("datapages")
    .dataset("peekbank:a3v0", version="v1.4")
    .table("administrations")
)

df = table.to_pandas_dataframe()
```

Authentication uses a `REDIVIS_API_TOKEN` environment variable. For queries and the R and JavaScript clients, see the <a href="https://apidocs.redivis.com/client-libraries" target="_blank">Redivis client documentation</a>.
