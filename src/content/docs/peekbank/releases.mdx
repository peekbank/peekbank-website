We release new versions of the Peekbank database as new data becomes available. To ensure reproducibility, we maintain database versions associated with each publication by the Peekbank team. The `peekbankr` package will always use the initial database version by default. The R API `peekbankr` can be directed to use any recent database version by using the `db_version` parameter.
