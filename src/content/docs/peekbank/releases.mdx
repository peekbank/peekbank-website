title: Releases
description: The Peekbank database releases and the Redivis version each maps to.
---

We release new versions of the Peekbank database as new data becomes available. To ensure reproducibility, we maintain database versions associated with each publication by the Peekbank team. To pin one, pass it to `connect_to_peekbank()` as `db_version`; `get_db_info()` lists the releases available and the Redivis version each maps to.

**`connect_to_peekbank()` currently defaults to 2021.0, pass `db_version = "2026.1"` for the full current database.**
