---
title: Framework
description: How Peekbank data is processed, released and accessed.
---

The Peekbank data framework consists of three components:

1. processing raw experimental datasets
2. publishing them as a versioned release
3. providing an interface to the data

The code used to process raw datasets is hosted in <a target="_blank" class="no-underline" href="https://github.com/peekbank/peekbank-data-import" style="color:#3399f3"><code>peekbank-data-import</code></a>, which holds one import script per dataset, converting each lab's raw eye-tracking data into the common schema. The conversion and validation helpers those scripts rely on ship as part of <a target="_blank" class="no-underline" href="https://github.com/peekbank/peekbankr" style="color:#3399f3"><code>peekbankr</code></a>.

Each release is published to Redivis: the tables themselves in the <a target="_blank" class="no-underline" href="https://stanford.redivis.com/datasets/a3v0-3drqa89kg" style="color:#3399f3">peekbank dataset</a>, and the raw data, processed data and per-dataset READMEs in <a target="_blank" class="no-underline" href="https://stanford.redivis.com/datasets/frvk-5c922jwkx" style="color:#3399f3"><code>peekbank_files</code></a>. Every Redivis version holds one named Peekbank release, such as 2026.1, so an analysis can be pinned to the data it was run against.

The <a target="_blank" class="no-underline" href="https://peekbank.github.io/peekbankr/index.html" style="color:#3399f3"><code>peekbankr</code></a> library (R) provides an application programming interface, or API, that offers high-level abstractions for accessing that data. Other languages can read the tables from Redivis directly.

The <a class="no-underline" href="../../analyses/accuracy/" style="color:#3399f3">interactive analyses</a> provide a tool for exploring the data in the browser.
