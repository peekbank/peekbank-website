The Peekbank schema is a set of tables linked by IDs, each accessible through <a href="../../start/peekbankrapi/" target="_blank">peekbankr</a>. For details on the fields of each table, refer to the <a href="../codebook/" target="_blank">codebook</a>.

If you need a refresher on tables, keys and joins, the <a href="https://r4ds.hadley.nz/joins.html" target="_blank">Joins chapter of R for Data Science</a> covers them.

The schema changed with release 2025.1; pick the tab for the release you are using.

<Tabs syncKey="schema">
<TabItem label="2025.1 onward">

| Table | One row is |
| --- | --- |
| <a href="../codebook/#datasets" target="_blank" class="whitespace-nowrap no-underline"><code>datasets</code></a> | a contributed dataset, with its citation |
| <a href="../codebook/#subjects" target="_blank" class="whitespace-nowrap no-underline"><code>subjects</code></a> | a participant |
| <a href="../codebook/#administrations" target="_blank" class="whitespace-nowrap no-underline"><code>administrations</code></a> | one session a participant took part in, with their age and the tracker used |
| <a href="../codebook/#trials" target="_blank" class="whitespace-nowrap no-underline"><code>trials</code></a> | a trial a participant completed, in order, with whether the original study excluded it |
| <a href="../codebook/#trial_types" target="_blank" class="whitespace-nowrap no-underline"><code>trial_types</code></a> | a type of trial, defined by its target and distractor stimuli, target side and carrier phrase |
| <a href="../codebook/#stimuli" target="_blank" class="whitespace-nowrap no-underline"><code>stimuli</code></a> | a word–image pair |
| <a href="../codebook/#aoi_timepoints" target="_blank" class="whitespace-nowrap no-underline"><code>aoi_timepoints</code></a> | a 25 ms gaze sample: target, distractor, other or missing |
| <a href="../codebook/#xy_timepoints" target="_blank" class="whitespace-nowrap no-underline"><code>xy_timepoints</code></a> | a 25 ms gaze sample as screen coordinates (where available) |
| <a href="../codebook/#aoi_region_sets" target="_blank" class="whitespace-nowrap no-underline"><code>aoi_region_sets</code></a> | the screen positions of the left and right areas of interest (where available) |
